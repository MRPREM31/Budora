\section{Introduction \& Architecture}
% ==============================================================================

Modern operating systems historically treat wireless earbuds, headphones, and Bluetooth audio accessories as generic monolithic audio sinks. When you pair an advanced set of True Wireless Stereo (TWS) earbuds to Windows or Android:
\begin{itemize}
    \item Individual battery levels for the \textbf{Left Earbud} and \textbf{Right Earbud} are flattened or hidden.
    \item The \textbf{Charging Case} battery percentage is completely inaccessible because the case itself shuts down its Bluetooth radio once the earbuds are deployed.
    \item Users are forced to install heavyweight, manufacturer-specific OEM applications burdened with background account synchronisation, location telemetry, and intrusive advertising.
\end{itemize}

\textbf{Budora} provides a cross-platform (Windows 11/10 and Android 12+) zero-telemetry, 100\% offline monitoring architecture. It passively sniffs Bluetooth Low Energy (BLE) broadcast frames, extracts Google Fast Pair and Apple Proximity payload packets, and renders real-time three-component readouts without requiring internet permissions or account creation.

\begin{infobox}[Core Architecture Tenets]
\begin{enumerate}
    \item \textbf{100\% Offline by Design:} Budora declares no network permissions (\texttt{android.permission.INTERNET} is omitted from the Android manifest, and the Windows service opens no external sockets).
    \item \textbf{Dual-Engine Parsing:} Decodes Google Fast Pair Service (\texttt{0xFE2C}) component frames and Apple Proximity Pairing (\texttt{0x004C}) manufacturer frames concurrently.
    \item \textbf{Smart Case Memory:} Automatically persists the last verified case battery reading when the lid closes and buds are docked or removed.
    \item \textbf{Universal Classic Fallback:} Detects active Bluetooth speakers and soundboxes (e.g., boAt Stone, WS-036, JBL Flip) via Windows Core Audio (MMDevices) and Android A2DP/HFP profile managers.
\end{enumerate}
\end{infobox}

\subsection{Category 3: Universal Bluetooth Audio \& Speaker Box Fallback}
For standard Bluetooth devices that do not broadcast BLE Fast Pair beacons, Budora falls back to Windows Core Audio (MMDevices) and classic Bluetooth profile tracking.

\begin{itemize}
    \item \textbf{Supported Speaker Boxes:} boAt Stone series (Stone 180, 260, 650, 1200, 1500), WS-036 / WS series soundboxes, JBL Flip (4, 5, 6), JBL Charge (4, 5), JBL Go series, Marshall Emberton, Sony SRS-XB series, Tribit StormBox, and desktop Bluetooth soundbars.
    \item \textbf{Display Behaviour:} Automatically activates \textbf{Single-Gauge Mode}, flagging the device as \texttt{Connected \& Active} with dedicated speaker icons.
\end{itemize}

\begin{tipbox}[How to Test If Your Earbuds Support Fast Pair]
\begin{enumerate}
    \item \textbf{Packaging Check:} Inspect the box for the official \textit{"Google Fast Pair"} logo or \textit{"Works with Android"} badge.
    \item \textbf{Out-of-the-Box Proximity Probe:} Turn on Bluetooth and Location on an unlocked Android 12+ phone. Open the charging case next to the phone. If a native Google prompt appears asking to pair, the device is fully compatible.
    \item \textbf{Spec Sheet Search:} Search the manufacturer's technical specifications for \texttt{GFPS} (Google Fast Pair Service) or BLE Advertising Protocol \texttt{0xFE2C}.
\end{enumerate}
\end{tipbox}

\section{Android Mobile Operations Guide}
% ==============================================================================

\subsection{Installation \& System Permissions}
\begin{enumerate}
    \item \textbf{Direct APK Installation:} Transfer \texttt{Budora.apk} to your phone and install via any file manager, or run via ADB:
    \begin{lstlisting}[language=bash]
adb install -r app/build/outputs/apk/debug/app-debug.apk
    \end{lstlisting}
    \item \textbf{Permission Granting:}
    \begin{itemize}
        \item \textbf{Nearby Devices (\texttt{BLUETOOTH\_SCAN} \& \texttt{BLUETOOTH\_CONNECT}):} Required to listen for low-energy advertisements. Note: Budora declares the \texttt{neverForLocation} flag, guaranteeing zero GPS or physical tracking.
        \item \textbf{Display Over Other Apps (\texttt{SYSTEM\_ALERT\_WINDOW}):} Enables the floating edge connect drawer to slide over launcher and third-party apps upon connection.
        \item \textbf{Notifications (\texttt{POST\_NOTIFICATIONS}):} Powers the persistent single-line status notification and low-battery alerts.
    \end{itemize}
\end{enumerate}

\subsection{Core Features \& Interface Elements}
\begin{itemize}
    \item \textbf{Dual Battery Rings:} Left and Right earbud rings display semantic color bands:
    \begin{itemize}
        \item \color{BudoraGreen}\textbf{Green ($> 40\%$):} \color{black} Healthy charge.
        \item \color{BudoraOrange}\textbf{Orange ($21\% - 40\%$):} \color{black} Moderate battery.
        \item \color{BudoraRed}\textbf{Red ($\le 20\%$):} \color{black} Low battery warning threshold.
    \end{itemize}
    \item \textbf{Smart Case Memory (\texttt{\~{}}):} When earbuds are in active use, the charging case BLE radio sleeps. Budora retains the last known case level (e.g., \texttt{\~{}70\%}) along with a timestamp (\textit{"last seen 2 min ago"}).
    \item \textbf{In-Case Docking Indicator:} When an individual pod is returned to the case, its gauge dims and displays \texttt{(In Case)}, reflecting power-dock status.
    \item \textbf{Now Playing Card:} Integrates with Android's notification listener to surface track metadata and live album artwork directly underneath the telemetry rings.
\end{itemize}

\subsection{Settings \& Customization}
Open Settings by tapping the gear icon (\texttt{\#990, 297}) in the top-right header:
\begin{itemize}
    \item \textbf{App Logo \& Branding:} Toggle between the official Budora squircle emblem or upload a custom image. Choose between \textit{Round}, \textit{Side Round}, or \textit{Square} silhouette clipping.
    \item \textbf{Color Palettes:} Select from five themes: \textbf{Default}, \textbf{Ocean}, \textbf{Sunset}, \textbf{Forest}, and \textbf{Grape}.
    \item \textbf{Edge Drawer Preferences:} Set the popup anchor position (\textit{Bottom} vs. \textit{Top}) and customize the auto-dismiss timer (3s, 8s, 15s, or manual swipe).
\end{itemize}

\section{Windows Desktop Operations Guide}
% ==============================================================================

\subsection{Quick Launch \& Standalone Execution}
\begin{enumerate}
    \item \textbf{One-Click Launch:} Double-click \texttt{run.bat} located in the Budora root directory. The script resolves local Python 3.11 executables and boots \texttt{windows/main.py} in background mode.
    \item \textbf{Manual Startup:}
    \begin{lstlisting}[language=bash]
cd windows
python main.py
    \end{lstlisting}
    \item \textbf{Single-Instance Guard:} Budora utilizes a local IPC socket (\texttt{Budora\_SingleInstance\_IPC\_Socket}). Launching \texttt{run.bat} while an instance is already active brings the existing dashboard immediately to the foreground.
\end{enumerate}

\subsection{Desktop Features}
\begin{itemize}
    \item \textbf{Fluent Floating Connect Flyout:} Pops up smoothly in the bottom-right corner above the Windows taskbar whenever your earbuds or speaker connect.
    \item \textbf{Speedometer Rev-Up Animation:} Circular vector gauges smoothly animate from 0\% up to target telemetry values upon appearance.
    \item \textbf{System Tray Companion:} Minimises to the Windows notification tray. Left-click toggles the main window; right-click opens the context menu (Settings, Re-scan, Disconnect, Exit).
    \item \textbf{Windows GSMTC Media Integration:} Queries Windows Global System Media Transport Controls to display track title, artist, album thumbnail, and playback transport controls (Play, Pause, Next, Previous) directly inside the desktop dashboard.
\end{itemize}

\section{Troubleshooting \& Frequently Asked Questions}
% ==============================================================================

\begin{warnbox}[Frequently Encountered Issues]
\textbf{Q: The floating popup did not appear on Android when my earbuds connected.} \\
\textbf{A:} Ensure that \textit{Display Over Other Apps} (\texttt{SYSTEM\_ALERT\_WINDOW}) is toggled ON under Android Settings $\rightarrow$ Apps $\rightarrow$ Budora $\rightarrow$ Appear on Top. On devices running ColorOS or MIUI, verify that background auto-start permissions are enabled.

\vspace{6pt}
\textbf{Q: Why does the case battery have a tilde (\texttt{\~{}}) prefix?} \\
\textbf{A:} The tilde indicates that the reading is from \textbf{Smart Case Memory}. Because charging cases shut down their radio when both pods are removed, Budora displays the last verified percentage until the lid is opened again.

\vspace{6pt}
\textbf{Q: Windows shows my speaker as ``Connected \& Active'' but battery is ``--''.} \\
\textbf{A:} Classic Bluetooth speakers (such as WS-036 or soundbars) only expose standard audio endpoints without BLE battery GATT profiles. Budora accurately detects their active audio connection state without displaying false telemetry.
\end{warnbox}
